PAW / ORBIT 게임 실행 방법 (Windows)

1. ZIP 파일을 마우스 오른쪽 버튼으로 눌러 '모두 압축 풀기'를 선택합니다.
2. 압축을 푼 Paw-Orbit 폴더를 엽니다.
3. '실행하기.bat'을 더블클릭합니다.
4. 브라우저에서 게임이 열립니다. 게임을 종료한 뒤 검은 실행 창에서 Ctrl+C를 누르면 서버가 꺼집니다.

중요: ZIP 안에서 바로 실행하지 말고, 먼저 압축을 풀어 주세요.
'index.html'을 직접 더블클릭하면 브라우저 보안 설정 때문에 버튼과 게임 기능이 동작하지 않을 수 있습니다. 반드시 '실행하기.bat'으로 실행하세요.

Windows 보안 알림이 나오면 'Windows PowerShell' 실행을 허용해야 합니다. 이 실행기는 게임 폴더 안에서만 로컬 서버를 열며 인터넷에 게임 데이터를 전송하지 않습니다.
